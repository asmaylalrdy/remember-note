# 📝 Rady Note (v3.5)
> تطبيق ملاحظات ذكي مع نظام تنبيه متطور وتصميم دافئ جذاب.

تطبيق **Rady Note** هو رفيقك اليومي لتنظيم أفكارك وضمان عدم نسيان مواعيدك. تم تصميمه ليكون خفيفاً، سريعاً، ومتوافقاً تماماً مع الهواتف المحمولة.

---

## ✨ المميزات الرئيسية
* **🔔 نظام تنبيه ذكي:** إشعارات حقيقية تظهر على شاشة القفل مع صوت تنبيه لضمان عدم فوات الموعد.
* **🎨 تصميم دافئ (Gemini Style):** واجهة مستخدم بألوان ذهبية وبرتقالية مريحة للعين وفخمة في الوضع الداكن.
* **📄 تصدير PDF:** إمكانية تحويل ملاحظاتك إلى تقارير PDF منظمة بضغطة زر.
* **🔍 بحث سريع:** محرك بحث لحظي للعثور على أي ملاحظة وسط مئات الملاحظات.
* **📤 مشاركة التطبيق:** زر مدمج لمشاركة رابط التطبيق مع أصدقائك بسهولة.
* **📱 متجاوب بالكامل:** واجهة مصممة خصيصاً لتناسب شاشات الهواتف المحمولة وتعمل كتطبيق (PWA).

---

## 🛠️ التقنيات المستخدمة
* **HTML5 & CSS3:** مع استخدام تقنيات الـ Flexbox و Grid للتصميم المتجاوب.
* **JavaScript (Vanilla):** لإدارة البيانات محلياً (LocalStorage) وتشغيل نظام المنبه.
* **Web Share API:** للمشاركة الأصلية عبر تطبيقات التواصل.
* **html2pdf.js:** لتحويل المحتوى البرمجي إلى ملفات PDF.
