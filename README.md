## ✨ المميزات الرئيسية
* **🔔 نظام تنبيه ذكي:** إشعارات حقيقية تظهر على شاشة القفل مع صوت تنبيه (Beep) لضمان عدم فوات الموعد.
* **🎨 تصميم دافئ (Gemini Style):** واجهة مستخدم احترافية بألوان ذهبية وبرتقالية فخمة ومريحة للعين.
* **📄 تصدير PDF:** إمكانية تحويل ملاحظاتك ومواعيدك إلى ملفات PDF منظمة بضغطة زر.
* **🔍 بحث سريع:** محرك بحث لحظي للعثور على أي ملاحظة داخل ذاكرة التطبيق.
* **📤 مشاركة التطبيق:** زر مدمج لمشاركة رابط التطبيق (Vercel) مع الأصدقاء بسهولة.
* **📱 متجاوب بالكامل:** مصمم ليعمل بكفاءة عالية على كافة أنواع الهواتف الذكية.

---

## 🛠️ التقنيات المستخدمة
* **HTML5 & CSS3:** مع استخدام تقنيات الـ Flexbox والتصميم المتجاوب.
* **JavaScript (Vanilla):** لإدارة البيانات محلياً (LocalStorage) وتشغيل نظام المنبه الصوتي.
* **Web Notification API:** لإرسال التنبيهات المباشرة لنظام التشغيل.
* **html2pdf.js:** لإنشاء ملفات الـ PDF برمجياً.

## 🚀 كيف تستخدم التطبيق؟
1. افتح الرابط: [remember-note.vercel.app](https://remember-note.vercel.app)
2. اضغط على خيارات المتصفح واختر **"إضافة إلى الشاشة الرئيسية"** ليعمل التطبيق كأيقونة منبه مستقلة.
3. تأكد من تفعيل "إذن الإشعارات" عند الطلب ليعمل المنبه بنجاح.
