## ✨ المميزات الرئيسية
* **🔔 نظام تنبيه ذكي:** إشعارات حقيقية مع صوت تنبيه لضمان عدم فوات الموعد.
* **🎨 تصميم دافئ:** واجهة مستخدم بألوان برتقالية وذهبية مريحة وفخمة.
* **📄 تصدير PDF:** تحويل الملاحظات إلى ملفات PDF منظمة بضغطة زر.
* **🔍 بحث سريع:** العثور على الملاحظات لحظياً داخل الذاكرة.
* **📤 مشاركة التطبيق:** زر مخصص لنشر رابط التطبيق بسهولة.
