## ✨ المميزات الرئيسية
* **🔔 نظام التنبيه الذكي:** إشعارات حقيقية مع صوت تنبيه يضمن عدم فوات المواعيد.
* **🎨 تصميم أنيق:** واجهة مستخدم ذات لون ذهبي وفخم مريحة للعين.
* **📄 تصدير PDF:** إمكانية تحويل مذكراتك إلى ملفات PDF منظمة بضغطة زر واحدة.
* **🔍 بحث سريع:** العثور على المذكرات والمهام لحظياً داخل الذاكرة.
